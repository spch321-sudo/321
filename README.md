## 五個分頁

1. **今日** — 繼續閱讀、**讀經計畫**（每日一課約半年／每週一課約三年半／看聽想講行速成 33 課，每天告訴你該讀哪一課）、**每日提醒**（本機通知，App 開著或從背景回來時到點提醒；可設時間）、**複習宣告**（完成後第 3、7、30 天把該課的信心宣告再提出來）、今日金句、十單元環形進度。
2. **課程** — 十單元 173 課手風琴（自動展開你上次所在的單元），每單元附主題經文。每課四模式：
   - **讀**：完整版講章（主題經文、引言、經文背景、要點、321整合、應用操練、結語），句子畫線＋領受＋問小智、真人語音朗讀跟讀、操練勾選（記入操練簿、可指定為哪一位「2」操練）、信心宣告（點一下宣告句存入宣告簿，或自己寫）、回應禱告、小組討論、標記完成、上一課／下一課。
   - **享**：部落格文章，一鍵複製全文／系統分享（含標籤與課別署名）。
   - **講**：12 張（15 分鐘）／21 張（30 分鐘）投影片文字，每張可展開「講解重點」與「口語逐字稿」；一鍵匯出投影片文字貼進簡報軟體；直接進入提詞機。
   - **帶**：全螢幕提詞機（投影片精簡版逐張 → 小組討論題（可標記已討論）→ 信心宣告 → 本週操練），螢幕保持喚醒、分段計時；並列出討論題、操練與教導誠信檢核入口。
3. **工具** — 321旅程地圖（八大步驟 × 十單元，依閱讀／畫線／宣告／操練／檢核／重讀／完成／分享自動推算）、920操練簿（我的「2」名單、操練紀錄、九樣果子）、關鍵詞軌跡、教導誠信檢核（11 項固定清單，只列出讀過的課）、講員工具箱。
4. **陪讀** — 小智．落實教練：系統提示詞內建 321 理念全文與目前課別的主題經文、操練；每則回答「先聖經、再321、最後一個最小行動」。範例問題十單元各 20 題（正式版，逐題編寫，涵蓋該單元各課與 321 核心概念）。回答可朗讀、收合、收藏、刪除。
5. **我的** — 進度、宣告簿、操練紀錄、畫線筆記（含領受摘要）、收藏、外觀、字級、朗讀聲音、**資料匯出／匯入**（JSON 備份，換手機不遺失）。

## 部署到 GitHub Pages

1. 在 `spch321-sudo` 帳號下新建 repo（例如 `luoshi321`）。
2. 用「Add file → Upload files」把本資料夾全部檔案上傳到 repo 根目錄（不用子資料夾）。單元分包最大的是 u8（3.2 MB），手機上傳請有耐心。
3. Settings → Pages → Source 選 `main` 根目錄。網址會是 `https://spch321-sudo.github.io/luoshi321/`。
4. 之後更新內容，記得遞增 `sw.js` 的 `VERSION`，已安裝的使用者才會看到更新。

## 已知限制／待辦

1. **語音與小智代理沿用領導力 App 的既有請求格式**（azure-tts / xiaozhi-proxy 兩個 Worker），本沙盒無法連線實測，請部署後實機測一輪朗讀與對話。
2. **簡體版為 OpenCC 自動轉換**，未經人工校對。英文版見 v1.1.0。
3. **沒有「想更深」問答**（文稿沒有現成題庫）。可由小組討論題與講解重點半自動生成初稿後審定。
4. **每日提醒**是 PWA 本機通知：只在 App 開著或從背景切回時檢查（iOS 需先「加入主畫面」並允許通知）；沒有伺服器推播。
5. **操練**：161 課來自文稿的「操練一：」標題；12 課由編輯自文稿操練段落整理。
